Unofficial build · Xteink X3 & X4 Pro

A few more reasons to pick up your reader.

An unofficial build of CrossInk v1.6.1 with a Reading Heatmap sleep screen, auto-hiding status bars and a Minimal Carousel home screen. Install it from your browser in about a minute.

  1. Open this page in Chrome or Edge on a computer.
  2. Plug in your reader with a USB-C data cable and turn it on.
  3. Click Install, pick the device, and wait until it says done.
  4. Turn on the features you want (see below).

This browser can't talk to USB devices. Use Chrome or Edge on a computer.

Your settings and SD card are kept; nothing is erased. USB-locked device? Use the SD card method.

Installs into the X4 Pro's spare firmware slot, like the official installer. The bootloader, partition table and the firmware it runs now aren't touched, and your settings and SD card are kept.

Keep it awake on its home screen while installing. If the browser can't find it, take out the SD card and try again. When it's done, unplug and replug the cable, then hold power to start it.

Flash your own .bin instead

Pick a CrossInk firmware file for the X3 or X4 Pro (for example firmware-x3-x4.bin or firmware-x4-pro.bin from a build). It's read by your browser and sent straight to the device; nothing is uploaded.

Good to know

Read these before installing.

  • Made for the X3. It's tested on the X3. The X4 Pro build is untested on a real device, so only try it if you're comfortable recovering your reader. The original X4 also runs it, but without the Reading Heatmap.
  • Reading Heatmap needs a clock chip (the X3 and X4 Pro have one; the original X4 doesn't), reading stats turned on, and the right date and time. Minutes count from install onward.
  • Heatmap page numbers use CrossInk's stable page numbers, so run your EPUBs through the EPUB Optimizer here. Without it the page count stays blank.
  • USB-locked device? Download the .bin from the release and use Settings → System → SD Card Firmware Update (needs CrossInk installed first).
  • English only for the new labels.
  • Unofficial. This is a fork of CrossInk, so please don't report issues to the CrossInk developers. To go back, change the sleep screen first, then install official CrossInk from Inky.
